Primeira rodada: portas `ep_e01_door_left_albedo_v001.png` e
`ep_e01_door_right_albedo_v001.png` (36×86), visor
`ep_e01_display_albedo_v001.png` (38×12). Metal/piso 16×16 são opcionais.
PNG RGB ou RGBA totalmente opaco, sem antialiasing, sem margem ou escala extra.
Guardar revisões com versões novas, acompanhadas de nota da autora/proposta.

Receber um PNG aqui **não o aplica automaticamente ao jogo**. Desenvolvimento
validará os arquivos e criará os materiais/referências específicos em uma etapa
de integração autorizada. Preservar os `.import` gerados para cada PNG novo.
